# Competitive baselines for 1D Burgers

[Notebook: Burgers_FFNO_UNetAR_CNOdirect.ipynb](Burgers_FFNO_UNetAR_CNOdirect.ipynb)

Implementation and evaluation framework for F-FNO, autoregressive U-Net, and direct CNO. Uses an initial-condition-only temporal protocol, which differs from the ten-known-state H10 evaluations.

The HDF5 dataset and trained checkpoints are not archived. Adjust data/output paths to run in Google Colab.
