# U-NO-H10 baseline

[Notebook: UNO1D_H10_Burgers.ipynb](UNO1D_H10_Burgers.ipynb)

A 1D U-NO-inspired spectral encoder-decoder using ten known input states, followed by recursive one-step forecasting. The notebook reports six training-set sizes (25–800), absolute physical full-trajectory/final-time L2, time and parameter counts.

**Scope:** A researcher-developed 1D architecture adaptation and temporal evaluation protocol, not an official benchmark result from the U-NO authors. Different forecast chunking and training budgets prevent a strictly controlled architecture-only comparison with AWFNO.
