# AWFNO-H10-K5

[Notebook: AWFNO_H10_K5_Burgers.ipynb](AWFNO_H10_K5_Burgers.ipynb)

1D Burgers sample-size study with ten observed past states, five-step forecast chunks, width 32, four layers, 16 Fourier modes and local radius three. Training set sizes: 25, 50, 100, 200, 400 and 800 trajectories.

The notebook reports absolute physical full-trajectory/final-time L2, fit/inference times, and parameter count. This is a sample-size sweep, not a three-seed repeat. Set Google Drive data/output paths before running.
